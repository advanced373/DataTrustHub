# DataTrustHub

A secure data management platform with policy-based access control: users belong to organizations,
policies define access rules, clearances link users to policies, and data items are files classified
by security level.

## Getting started

The solution targets .NET 10 (LTS), so you need the .NET 10 SDK. See
[docs/development-setup.md](docs/development-setup.md) for the User Secrets (connection string,
JWT signing key, admin seed), the local database, and how to build and test.
